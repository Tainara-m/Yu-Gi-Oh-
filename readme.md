# ⚔️ Yu-Gi-Oh! Joken Pô Edition

Um jogo interativo inspirado no universo de **Yu-Gi-Oh!**, que combina a dinâmica do clássico Joken Pô (pedra, papel e tesoura) com elementos visuais e sonoros da franquia.

O projeto apresenta uma arena de duelo, cartas temáticas, personagens, efeitos sonoros e uma interface inspirada em jogos de RPG.

## 🎮 Sobre o projeto

O **Yu-Gi-Oh! Joken Pô Edition** foi desenvolvido como um projeto de programação com o objetivo de explorar a aplicação da lógica de programação na criação de jogos interativos.

A proposta é transformar uma brincadeira conhecida em uma experiência temática, utilizando recursos visuais, animações e elementos multimídia para proporcionar uma interação mais imersiva.

## ✨ Funcionalidades e recursos

- **Sistema de pontuação:** acompanhamento das vitórias e derrotas durante as partidas.
- **Interface de duelo:** área visual para exibição das cartas do jogador e do computador.
- **Cartas temáticas:** elementos gráficos inspirados em monstros e símbolos de Yu-Gi-Oh!.
- **Efeitos sonoros:** reprodução de sons para diferentes momentos do jogo.
- **Música de fundo:** trilha sonora temática.
- **Controle de áudio:** botão para ativar ou silenciar o som.
- **Vídeo de fundo:** recurso visual com reprodução automática e em loop.
- **Interface personalizada:** botões, molduras, cursores e elementos visuais com estética RPG.

## 🚀 Como executar

O projeto é uma aplicação web estática e não necessita de instalação de dependências ou configuração de servidor.

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha feito o download em ZIP.
3. Abra a pasta do projeto.
4. Execute o arquivo `index.html` em um navegador.

Também é possível acessar a versão publicada pelo GitHub Pages:

**[Acessar Yu-Gi-Oh! Joken Pô Edition](https://tainara-m.github.io/Yu-Gi-Oh-/)**
